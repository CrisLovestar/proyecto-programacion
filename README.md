🏍️ MotorSpecial

¡Bienvenido a MotorSpecial! Una landing page interactiva y moderna diseñada para los amantes de la velocidad y las superbikes. Este proyecto compara las cuatro marcas gigantes del motociclismo de pista: Yamaha, Ducati, Kawasaki y Suzuki.

🌟 Características Principales

Diseño Moderno y Oscuro: Interfaz elegante (Dark Mode) construida con Tailwind CSS, perfecta para la temática de motor.

Totalmente Responsivo: Se adapta perfectamente a computadoras de escritorio, tablets y teléfonos móviles.

Tarjetas Interactivas: Efectos hover suaves y diseño atractivo para presentar cada marca.

Tabla Comparativa Técnica: Enfrentamiento directo de especificaciones de las motos de 1000cc (R1, Panigale V4, ZX-10R y GSX-R1000).

Sinfonía Mecánica (Audios Reales): Reproductor de audio integrado en JavaScript vanilla para escuchar el rugido real de cada motor con solo presionar un botón.

Simulador de Preferencias: Un recomendador rápido e interactivo que sugiere una moto al azar con una breve justificación.

🛠️ Tecnologías Utilizadas

HTML5: Estructura semántica del proyecto.

Tailwind CSS (CDN): Para los estilos, layout y animaciones rápidas.

JavaScript (Vanilla): Lógica del recomendador y control del reproductor de audio nativo.

FontAwesome: Íconos vectoriales para la interfaz.

🚀 Cómo ejecutar el proyecto localmente

Dado que este proyecto utiliza tecnologías frontend puras (sin necesidad de instalar node modules o un backend), ejecutarlo es muy sencillo:

Clona este repositorio en tu computadora:

git clone https://github.com/TU-USUARIO/motorspecial.git


Abre la carpeta en tu editor de código favorito (recomendado: Visual Studio Code).

Verifica los archivos multimedia: Asegúrate de que las imágenes (.jpg) y los sonidos (.mp3) estén en la misma carpeta raíz que el archivo index.html.

Ejecuta el proyecto:

Opción recomendada: Usa la extensión Live Server en Visual Studio Code para abrirlo y evitar bloqueos de seguridad del navegador con los audios.

Opción básica: Haz doble clic en el archivo index.html para abrirlo directamente en tu navegador web.

📁 Estructura de Archivos recomendada

Para que todo funcione correctamente a la primera, la estructura del proyecto debe verse así:
